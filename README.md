# What is Disignum?
Disignum is an app built for empowering deaf community. It is made to convert speech into sign language. Disignum is a Latin word that means “speech to sign”. After listening to the user, Disignum converts the detected speech into American Sign Language. We tried multiple ways, read a lot of research papers, and built some prototypes.  Though the project failed due to a lack of current technology and time available to us, it provided us with a huge amount of experience and learnings that will help in our further research projects. 

# Prototype #1 

In this, we used CrewAI to build an AI agent that can convert speech to sign language and used  WebSocket to build a web interface. We used a .glb 3d model and controlled it by giving values from 0 to 90 to its joints. The values were generated by the AI agent and sent to the website, and the animation was shown. Then the user was required to submit a review; if he liked the animation, he could save it in the database or suggest further improvements to it. If a command is already in the database, the animation is shown directly without referring to the AI agent. 

Limitations 
We want Disignum to be real-time, but the AI agent took about 20 seconds to process each sentence, and it cost a lot for the API. 
Also, as LLMs are not designed for this task, many of their generated animations were incorrect. 
So we went to a different approach. 

# Prototype #2 
Tanishq and I then started looking for other ways to convert speech to sign language. I found some ASL tutorials and got to know about glosses. So, after doing some more research, we built the following approach 
Speech2Text                Text2Gloss	       Gloss2Pose	Pose3dAnimation 

With this approach, theoretically we can translate speech to sign efficiently.   
We fine-tuned the MarianMT model for Text2Gloss and got excellent accuracy. 
Text2Gloss task was easy, and the open-source datasets were available. The next problem was Gloss2Sign. 

We tried to use MediaPipe and extract key points of human body joints by giving sign language videos. But this process did not work and required a significant amount of computational power, time, and effort. This was our bottleneck at Disignum. 
We read multiple papers, found different ways, but failed again and again at this step. I also tried to integrate Unity and MediaPipe, but that did not work well either. Training our own transformer model also did not work due to the scarcity of data. So we dropped the project in March 2026. 

It was a great journey, doing research, building entirely new code by ourselves, testing models, and then failing together.
